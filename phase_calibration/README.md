# Jicamarca Phase Calibration

This repository contains a collection of tools to calibrate the antenna modules of 
the Jicamarca Radio Observaotry, for interferometry experiments.

## Implemented Calibration approaches

This suite follows the methodologies described in *Chau et al. (2008)*.

1. Hydra A absolute calibration
2. Meteor head echoe relative calibration

## Dependencies

- Signal Chain v3.x
- Ephem
